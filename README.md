# D03T03. Структуры управления на языке C

Учебный проект школы 21 (School 21 / Ecole 42), посвящённый структурам управления на языке C: ветвлениям, циклам, рекурсии и итеративным алгоритмам. Все программы читают данные из `stdin` (или работают без ввода) и выводят результат в `stdout`.

## Стек и требования

- Язык: **C** (стандарт **C11**)
- Компилятор: **gcc**
- Флаги сборки: `-Wall -Wextra -Werror`
- Стиль кода: **Google C++ Style Guide**
- Вывод программ **не должен заканчиваться переводом строки** (кроме случаев, где это явно требуется заданием)
- Глобальные переменные запрещены
- Массивы и динамическая память в этом проекте запрещены
- Разрешённые библиотеки: `<stdio.h>`, `<math.h>`

## Структура репозитория

```text
.
├── README.md
└── src/
    ├── 1948.c
    ├── quest3.c
    ├── door_functions.c
    └── data/
        └── door_data.txt
```

Каждый файл `.c` в `src/` — самостоятельная программа с функцией `main`. Файл `src/data/door_data.txt` — результат работы `door_functions.c` (таблица значений функций), полученный перенаправлением вывода.

## Сборка

Пример для `quest3.c`:

```bash
gcc -Wall -Wextra -Werror -std=c11 src/quest3.c -o quest3
./quest3
```

Для программ, использующих `<math.h>` (`1948.c`, `door_functions.c`), добавьте `-lm`:

```bash
gcc -Wall -Wextra -Werror -std=c11 src/1948.c -o 1948 -lm
gcc -Wall -Wextra -Werror -std=c11 src/door_functions.c -o door_functions -lm
```

## Программы

### 1. `1948.c` — Наибольший простой делитель (без деления)

Программа находит наибольший простой делитель заданного целого числа. По условию задания **запрещено** использовать операции деления `/` и взятия остатка `%`: деление реализовано через вычитание (функция `is_divisible`). Поиск выделен в отдельную функцию `get_max_prime_divisor`.

- **Вход:** одно целое число
- **Выход:** наибольший простой делитель
- **Ошибка ввода / 0 / 1:** `n/a`
- **Отрицательные числа:** берётся модуль
- **Библиотеки:** `<stdio.h>`, `<math.h>`

| Вход   | Выход |
|--------|-------|
| `100`  | `5`   |
| `-4`   | `2`   |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/1948.c -o 1948 -lm
echo 100 | ./1948
# 5
```

### 2. `quest3.c` — n-е число Фибоначчи (рекурсия)

Программа вычисляет n-е число Фибоначчи **рекурсивным** алгоритмом. Сам поиск выделен в отдельную функцию `fibonacci`.

- **Вход:** одно целое число `n`
- **Выход:** `n`-е число Фибоначчи
- **Ошибка ввода:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход | Выход   |
|------|---------|
| `21` | `10946` |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/quest3.c -o quest3
echo 21 | ./quest3
# 10946
```

### 3. `door_functions.c` — Таблица значений трёх функций

Программа рассчитывает и выводит таблицу значений трёх функций на интервале `[-π, π]` (42 замера, включая границы):

- **Верзьера Аньези** с единичным диаметром: `y = 1 / (1 + x²)`
- **Лемниската Бернулли** с единичным интервалом в положительной полуплоскости: `y = sqrt(sqrt(1 + 4x²) - x² - 1)` (при `Y > 0`)
- **Квадратичная гипербола**: `y = 1 / x²`

Формат вывода — четыре столбца, разделитель `|`, значения с точностью до 7 знаков после запятой:

```text
x | agnesi | bernoulli | hyperbola
```

Если функция не определена в точке, вместо значения выводится `-`. Заголовков таблицы нет. Число π задано через директиву `#define M_PI`.

- **Вход:** нет (фиксированный интервал)
- **Выход:** 42 строки таблицы
- **Библиотеки:** `<stdio.h>`, `<math.h>`

Запуск с сохранением результата в файл (перенаправление вывода в bash):

```bash
gcc -Wall -Wextra -Werror -std=c11 src/door_functions.c -o door_functions -lm
./door_functions > src/data/door_data.txt
```

Первые строки `src/data/door_data.txt`:

```text
-3.1415927 | 0.0919997 | - | 0.1013212
-2.9883442 | 0.1007029 | - | 0.1119796
...
```
